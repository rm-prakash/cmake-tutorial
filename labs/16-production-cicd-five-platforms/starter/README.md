# Chapter 16 — Student starter

Implement the capstone from a clean CMake project. Start with a static library that exports `EmbeddedCore::Core`; create the independent consumer, test it, then add scripts for Debug and Release on Linux. Next add Windows and Android toolchains, manifest verification, Jenkins and GitHub Actions orchestration, and a protected release policy.

Work through the chapter's experiments in order. The full solution lives in `../solution/`.
