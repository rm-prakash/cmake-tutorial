# Course Syllabus

**Title:** Modern CMake: From First Principles to Production CI/CD

**Project:** EmbeddedCore + DeviceSimulator

**Audience:** C++ developers and build/CI engineers, beginner to advanced CMake.

## Module I — Build Systems Foundations

1. [From C++ Source Code to an Executable](chapters/01-source-to-executable/README.md)
2. Compilers, Linkers, Object Files and Libraries
3. Make, Ninja and CMake: Understanding Build Systems
4. Installing CMake and Building Your First Project

## Module II — Core CMake

5. Understanding CMakeLists.txt and Targets
6. Variables, Scopes, Headers and Include Directories
7. Debug, Release and Build Configurations
8. Creating Static and Shared Libraries

## Module III — Intermediate CMake

9. DLLs, Runtime Dependencies and Deployment
10. Modular Projects and add_subdirectory()
11. Third-Party Dependencies, find_package() and FetchContent
12. Compiler Options, Definitions and Generator Expressions

## Module IV — Advanced CMake and Production Engineering

13. Cross-Compilation, Toolchains, Architectures and ABIs
14. Multi-Platform Dependencies: OpenSSL, Android and Artifact Repositories
15. CMake Presets, CTest, Installation and Package Exports
16. Jenkins, GitHub Actions and Production CI/CD

The advanced chapters will distinguish Linux/Android native development from bare-metal microcontroller firmware, and will use public, nonproprietary dependency examples.
