# Glossary

**ABI:** Application binary interface, the conventions allowing binary components to interoperate.

**Build system:** Tool coordinating compilation, linking and other build tasks.

**Compiler:** Tool translating source code into object code.

**CMake:** Tool describing, configuring and generating/driving builds.

**Executable:** Program in a format that a compatible execution environment can load and run.

**Linker:** Tool resolving symbols and producing linked outputs from objects and libraries.

**Object file:** Compiled machine code and metadata used as input to linking.

**Target:** In CMake, a modeled output or dependency such as an executable or library.
