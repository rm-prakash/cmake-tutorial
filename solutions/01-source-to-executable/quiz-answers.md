# Chapter 01 — Quiz answers

[← Chapter](../../chapters/01-source-to-executable/README.md)

1. **B. Translate source into object code.** The compiler turns source into target-compatible object code; a linker is normally needed for the executable.
2. **C. Linker.** Linking resolves symbols across object files and libraries.
3. **A. `/c`.** MSVC compiles the source without performing the final link.
4. **B. Old compiled code is executed.** The previously built executable is unchanged until you rebuild.
5. **D. A tool for configuring and generating/driving builds.** CMake is not a C++ compiler.
